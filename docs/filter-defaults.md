# 預設值設定

## 入口與操作

右上角頭像 → 帶設定圖示的「預設值設定」。這是帳號彈窗，不新增導覽目的地或路由。

- **專案**：沿用現有專案單選器；可選「不設定預設專案」清除。
- **團隊**：沿用團隊多選器，只保存整組團隊，不設定個別成員排除。全部取消勾選表示不設定預設團隊。
- **儲存**：保存本次草稿，成功才關閉；儲存失敗顯示錯誤並保留草稿，儲存期間鎖定操作。
- **取消／關閉**：不保存。有未儲存變更時先確認是否放棄；背景點擊及 Escape 不關閉彈窗。
- 說明文字精簡為「預設值只帶入之後進入頁面時尚未指定的條件」，不另外顯示瀏覽器保存提示。
- 關閉後焦點回到頭像；手機與桌面皆依內容決定彈窗高度，不預留固定空白，最高為視窗高度的90%。展開下拉時選項納入內容高度，過長時可捲動。專案／團隊仍使用各自共用的 160px／224px 選單尺寸，窄容器可縮限；其他編輯彈窗維持原有布局。

## 保存範圍

僅在**同一瀏覽器、同一網站 origin**以 localStorage 保存，依伺服器確認的登入帳號隔離。重新整理可還原；切換帳號不沿用另一帳號的預設值，不跨瀏覽器或裝置同步。清除網站資料會清除設定；登出本身不刪除設定。

版本化資料只包含專案 key 與團隊 group。專案及團隊都使用既有定義驗證；團隊會去重並依設定順序排列。不保存成員名單、成員排除、Jira Issue、OAuth Token 或其他憑證。成員仍由原有登入區域記憶體快取與 Jira 服務處理，設定不是授權來源。

瀏覽器禁止儲存、格式損毀、未知版本或過大資料不會使頁面失效；還原失敗視為未設定，明確儲存失敗則顯示錯誤，不假稱成功。

## 套用時機與優先權

預設值是**進入頁面時的一次性初始值**，不是持續綁定。儲存或其他分頁更新設定不會重設正在使用的篩選器、不直接提交查詢。重新整理或之後離開再進入相容頁面時，才重新檢查未指定條件。

1. URL 已指定的條件優先；顯式空值、非法／重複參數及孤立 Sprint 不會以預設值修補。
2. 使用者先開始操作時，保留本次選取，不等設定還原後再覆蓋。
3. 儀表板既有可還原的專案／團隊草稿優先，包含刻意清空的選擇。
4. 只有符合條件且尚未指定的欄位才帶入預設值。專案 URL 初始化沿用既有 URL builder，以 replace 補上條件，不增加 history entry。

| 相容頁面 | 專案／團隊初始值 | 查詢行為 |
| --- | --- | --- |
| 儀表板 | 只帶入未套用、沒有既有記憶草稿的專案／團隊草稿 | 保持「自己」模式，不自動切換或提交團隊範圍 |
| 工作量分析 | 未指定的專案／團隊草稿；既有有效 URL 與錯誤狀態優先 | 手動按「查詢」才分析；所有所選團隊須完整載入 |
| 專案回顧與趨勢 | 乾淨入口可帶入專案；團隊只保留在本頁 | 不自動選 Sprint 或執行分析，仍需選 Sprints 及按查詢；分析引擎尚未開放 |
| 團隊分析 | 乾淨入口可帶入專案與原有瀏覽器本地近 1 月區間；團隊只保留在本頁 | 不自動執行分析；分析引擎尚未開放 |
| Planning | 乾淨入口可帶入專案與整組團隊 | 專案帶入後沿用原本 Sprint 解析與資料載入；團隊在成員完整就緒後套用站內過濾 |
| Burn Down | 乾淨入口可帶入專案與整組團隊；保留合法 `byResolved=1` 舊旗標 | 專案帶入後沿用原本 Sprint 解析及 SSE；原有逐人成員排除操作不變 |
| Capacity | 乾淨入口只帶入專案，沒有團隊欄位 | 沿用原本 Sprint 解析及 mock 展示 |

不套用至 Burn Down 日期明細彈窗、設定／報表頁或其他沒有相容篩選器的入口。團隊預設值不改變既有成員載入、完整性驗證、JQL 或伺服器授權。

## 程式與測試來源

- `lib/filter-defaults.ts`：模型、儲存與 URL 初始化判定；引用現有專案／團隊選項及 URL validators/builders。
- `components/filter-defaults-provider.tsx`：依帳號隔離的共享設定、storage 更新與一次性初始化 hooks。
- `components/filter-defaults-navigation.tsx`：乾淨入口的專案 URL 初始化。
- `components/app-shell/filter-defaults-dialog.tsx`、`account-menu.tsx`：彈窗草稿、儲存／放棄及帳號選單。
- `tests/filter-defaults.test.mjs`：真實模型／provider／初始化與頁面整合的離線測試，transport 與無關子 UI 使用 mock。
- `tests/filter-defaults-dialog.test.mjs`、`tests/account-menu.test.mjs`：彈窗／選單、失敗／重試、焦點與共用尺寸回歸。

這些測試不代表已登入瀏覽器實測、部署驗證或真實 Jira 寫入。
