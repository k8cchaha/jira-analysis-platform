# 儲存的報表

[回功能總覽](../README.md) · 路徑：`/reports/saved/list` · 狀態：**規劃中（ComingSoon）**

## 目的
規劃讓使用者儲存並重新開啟報表設定，減少重複設定分析條件。

## 解決的問題
預期解決常用條件需要重新輸入的問題；目前尚無儲存、列表或開啟操作。

## 可以找到的 Insight
這是報表管理能力，不是新的分析指標。未來可透過固定設定重複觀察同一問題，但目前沒有已儲存的報表可使用。

## 使用方式
閱讀開發中提示；不能新增、編輯、刪除或分享報表設定。

## 指標與判定規則
未定義。**儲存設定不等於保存 Jira 資料快照**；未來是否儲存資料、如何重查與誰可使用仍須另訂契約。

## Jira 資料依據
本頁沒有 JQL、REST request 或資料持久化；未接報表設定儲存機制。

## 限制與解讀注意事項
其他頁 URL 能還原條件不代表已有 Saved Reports。未來重查設定可能因 Jira 現值改變而得到不同結果。
