# 專案回顧與趨勢

[回功能總覽](../README.md) · 唯一入口：`/analytics/projects` · 狀態：**部分實作（沿用Projects篩選介面，分析尚未開放）**

## 目的
整合原專案分析、趨勢分析與比較分析的產品入口，規劃讓使用者以專案為主體，在指定 Sprint 或日期區間回顧 Jira 工作，追查跨期間趨勢，並在相同條件下討論差異。

**目前可用的是專案／區間條件選擇、URL 還原與驗證；回顧、趨勢與比較共用這個入口。** 分析區仍顯示 ComingSoon，沒有可用的分析引擎、圖表、計算或比較對象選取器。

## 解決的問題
預期降低跨 Sprint 與日曆區間切換不一致、分析範圍不清楚，以及回顧、趨勢與比較入口分散造成的口徑誤解。目前完成的是篩選條件與入口整合，不是分析結果。

## 可以找到的 Insight
**目前沒有分析數字、趨勢或比較圖表可供判斷。** 以下僅為未來可討論的問題，不是既有功能或交付承諾：

| 規劃問題 | 未來需具備的訊號 | 可能行動 |
| --- | --- | --- |
| 專案在指定期間的工作構成如何？ | 明確母體的工作量／點數摘要與可核對明細 | 回顧集中項目、缺值與範圍後再追查原票 |
| 不同 Sprint 或日期期間的工作是否持續變化？ | 固定期間粒度、定義一致的跨期指標與資料品質資訊 | 區分短期波動與長期變化，核對指派／範圍變動 |
| 相同條件下的工作構成有哪些差異？ | 同一期間、對象類型、母體與計算條件的可對帳結果 | 先核對點數尺度、角色與範圍，再追查差異來源 |

指標、完成定義、可比較對象及歷史母體尚未定案。沒有移動平均、Velocity、趨勢線、異常偵測、預測或排行榜；不應從此頁推導改善、退步、因果或績效結論。

## 使用方式
- 專案單選且必選；未選之前 Team、區間模式、Sprints、日期（含快捷鍵）與查詢不可操作。
- **Sprints／分析區間二選一**，兩者保持可見但只有啟用模式可操作。預設 Sprints 模式，沒有預選 Sprint；Sprints 可複選該專案的完整本機設定清單（含歷史與未來，最新在前），至少一個才能查詢。
- 日期模式的初始草稿為瀏覽器本地日期的近1月，支援近1／2／3／6月與自訂日期；這是滾動日曆月而非固定30天，也不表示預設已啟用日期模式。還原的 URL 日期優先；有效範圍為含首末日、真實且順序正確的 `YYYY-MM-DD`，最多3,660天。
- Team 僅選整個團隊、不提供逐成員排除；留在本頁本次狀態，未作為分析 URL／Jira 分析條件，也不是比較對象選取器。
- Project、Sprints、模式與完整有效日期選擇即時更新 URL；預設 Sprints 模式省略 `mode`、以重複 `sprint` 表示複選，日期模式的區間條件只序列化 `mode=dates` 與 `from`／`to`（兩種模式均保留 `project`）。查詢只驗證並確認條件，顯示分析尚未開放、不查詢分析資料的提示。
- 切換模式保留未啟用區間的本頁草稿，但 URL 僅含啟用區間。更換專案清除舊專案的 Sprint 草稿，保留日期與 Team；重新整理不保存 Team／未啟用區間草稿。上一頁／下一頁從有效 URL 還原啟用模式與條件，不執行分析查詢。
- 未知模式／參數、重複單值參數、混合 Sprint／日期條件、不完整或無效日期、其他專案的 Sprint 都會明確報錯；無效 URL 不能啟用查詢，不會自動修正或擴大範圍。
- 原 `/analytics/trends`、`/analytics/comparison` 頁面已移除；其根路徑及已知子頁別名以 **307直接跳轉**至 `/analytics/projects`，不經另一個舊入口。跳轉保留所有 query 值（包括未知、無效與重複值），不在跳轉層驗證、捨棄或修正；抵達本頁後仍依上述既有篩選契約驗證。未知子路徑不列為跳轉別名。

## 指標與判定規則
尚無分析母體、聚合公式、歷史重建或完成規則。不要套用工作量／Burn Down 的計算，或因有日期欄位、複選 Sprint 或整合比較入口便認為已查詢 Jira或產生分析。

## Jira 資料依據
- **沒有專案回顧與趨勢的分析 JQL 或分析 REST request。** 不將共用但未接入的 analysis builders 當作本頁實作；入口整合不新增 Jira 資料管線或寫入。
- Project／Sprint 來自程式內設定，不使用 Jira Agile Sprint API；共用 Team 元件可能讀取 Jira 團隊成員 metadata，這不等於取得專案分析資料。
- 未使用分析結果欄位。未來實作仍應遵守 [Jira 技術參考](../jira-reference.md) 的集中 builder／授權契約。

## 限制與解讀注意事項
條件可選、URL 可還原、按鈕可啟用與舊入口可跳轉，都不代表分析引擎已完成；沒有可匯出、可跨期分析或可比較的結果。未來歷史回顧需處理範圍、欄位、父子關係與指派變動；不同點數尺度、工作母體、角色或出勤不能直接橫比。現有期間內的週分布請見 [工作量分析](analytics-workload.md)，其母體與公式不因此變更。
