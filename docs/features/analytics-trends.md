# 趨勢分析

[回功能總覽](../README.md) · 路徑：`/analytics/trends` · 狀態：**規劃中（ComingSoon）**

## 目的
規劃掌握 Jira 工作隨時間產生的變化。

## 解決的問題
預期協助區分短期波動與長期變化；目前未提供時間序列分析。

## 可以找到的 Insight
目前沒有趨勢結果。規劃問題：工作指標是否持續上升或下降？未來需有固定期間與一致口徑的時間序列，才能核對變化原因；不能宣稱已有異常偵測或預測。

## 使用方式
閱讀開發中提示；尚無期間、粒度、指標切換或趨勢查詢。

## 指標與判定規則
未定義。未提供移動平均、Velocity、趨勢線、預測或歷史快照。

## Jira 資料依據
本頁沒有實際 JQL、REST request 或欄位計算。

## 限制與解讀注意事項
未來的歷史比較需要處理範圍、欄位與指派變動；目前不能用此頁推導長期改善或退步。
