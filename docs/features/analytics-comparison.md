# 比較分析

[回功能總覽](../README.md) · 路徑：`/analytics/comparison` · 狀態：**規劃中（ComingSoon）**

## 目的
規劃在相同條件下，選擇 **2～4 個同類型對象**，比較工作量、點數等指標。

## 解決的問題
預期降低比較時期間、對象類型及計算條件不一致造成的誤解；現在尚無比較操作。

## 可以找到的 Insight
目前沒有比較結果。規劃問題：相同口徑下，哪些對象的工作構成不同？未來需要可對帳的同類對象指標，再追查差異；不以差異直接推論原因或績效。

## 使用方式
閱讀開發中提示。「2～4 個」是頁面描述的規劃範圍，不是目前可用的選取器。

## 指標與判定規則
尚未定義可比較對象、正規化、日期範圍及完成規則。

## Jira 資料依據
本頁沒有實際 JQL、REST request 或比較計算。

## 限制與解讀注意事項
不同點數尺度、工作母體、角色或出勤不能直接橫比；沒有已實作的排行榜。
