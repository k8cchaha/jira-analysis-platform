## 目的
保留工作區系統設定入口；目前不提供設定檢視、修改或診斷。

## 解決的問題
系統設定集中管理尚未實作。先前的暫時環境變數診斷已完整移除，不再透過此頁取得執行環境值。

## 可以找到的 Insight
沒有分析結果、系統健康指標或環境設定狀態。

## 使用方式
頁面只顯示「系統設定」標題，沒有 ComingSoon 內容、說明、欄位或操作按鈕。

## 指標與判定規則
沒有可管理的設定或判定規則。原環境項目、讀值 service、Client 診斷元件與敏感值 Server Action 均已移除，不只是把按鈕隱藏。

## Jira 資料依據
本頁沒有 JQL、Jira REST request、環境值讀取或設定寫入。應用程式 layout 的登入驗證、Auth.js、Jira OAuth 與部署所需環境配置維持原樣。

## 限制與解讀注意事項
路由與導覽仍存在，不代表已提供設定管理能力。此變更不會刪除實際環境變數，也不會修改登入或其他功能的授權政策。程式更新不代表已部署或實際瀏覽器驗證。
