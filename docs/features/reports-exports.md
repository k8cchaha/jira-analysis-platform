# 匯出紀錄

[回功能總覽](../README.md) · 路徑：`/reports/exports/list` · 狀態：**規劃中（ComingSoon）**

## 目的
規劃在匯出功能開放後，讓使用者檢視並下載報表。

## 解決的問題
預期降低交付報表時尋找檔案、辨識版本的負擔；目前沒有匯出紀錄或檔案。

## 可以找到的 Insight
這是成果交付與紀錄能力，不提供新的業務 Insight。目前不能確認「誰在何時匯出哪些條件」；這些紀錄欄位也尚未實作。

## 使用方式
閱讀開發中提示；尚無下載、重新匯出或紀錄檢索操作。

## 指標與判定規則
未定義檔案格式、快照語意、保留期限及下載權限。

## Jira 資料依據
本頁沒有 JQL、REST request、檔案生成或儲存機制。

## 限制與解讀注意事項
畫面顯示資料不等於已有匯出；本份 repository 說明文件也不是此產品的匯出紀錄。
